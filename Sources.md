# Déclaration des Sources


## 1. Historique des Prompts IA (Synthèse de nos requêtes)
Voici les principales requêtes que nous avons formulées à l'IA :

1.  *« Voici notre schéma relationnel de la base Tenrac, tu peux nous aider à faire un script Python avec Faker pour générer des milliers de membres, repas, etc. ? Comment on gère les boucles pour pas casser les clés étrangères ? »*
2.  *« Comment on peut faire dans le code python pour que certains champs comme Titre ou Dignite soient NULL de temps en temps ? Au hasard pour respecter nos pourcentages »*
3.  *« On a un code de création de tables mais il a été fait avec la syntaxe Oracle (avec des NUMBER, des VARCHAR2...). Tu peux nous le traduire pour que ça passe direct sur SQLite sans erreur ? Ça nous met des erreurs de syntaxe »*
4.  *« Petit souci avec random.randint pour les numéros de tel, ça s'insère sans le 0 au début dans le SQL, comment on force le 0 devant dans le f-string en Python ? »*
